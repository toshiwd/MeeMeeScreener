# TRADEX Image Rerank

The image branch is auxiliary only.
The numeric branch remains primary.

## Rules

- image rerank may rerank, veto, or boost
- image-only ranking semantics are forbidden
- renderer determinism is required
- time-block split and embargo are required
- numeric and image contributions must remain separable in artifacts and evaluation

## Phase scope

This phase does not promote image logic into the primary ranker.
It only keeps a minimal image smoke path available for research validation.
